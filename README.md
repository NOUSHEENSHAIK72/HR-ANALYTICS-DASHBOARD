# HR-ANALYTICS-DASHBOARD
HR Analytics Dashboard is a Power BI–based data analytics project that provides actionable insights into employee attrition, performance, salary distribution, and workforce diversity. The dashboard helps HR teams and management make data-driven decisions to improve employee retention,  and enhance overall organizational performance.
# 📊 HR Analytics Dashboard

## 📌 Overview
The **HR Analytics Dashboard** is an interactive business intelligence solution built using **Power BI** to analyze and visualize employee data. The project focuses on understanding workforce trends such as attrition, performance, salary patterns, and diversity to support strategic HR decision-making.

This dashboard enables HR professionals to identify problem areas, improve retention strategies, and optimize workforce planning through data-driven insights.

---

## 🎯 Objectives
- Analyze employee attrition and retention trends
- Monitor workforce distribution across departments
- Evaluate employee performance and satisfaction
- Study salary patterns based on experience and roles
- Support HR and management decisions using analytics

---

## 📊 Key Metrics (KPIs)
- Total Employees
- Attrition Rate (%)
- Average Salary
- Average Employee Tenure
- Department-wise Headcount
- Gender Diversity Ratio
- Performance Rating Distribution

---

## 📈 Dashboard Features
- Attrition analysis by department, age, and gender
- Employee performance and satisfaction insights
- Salary distribution and experience-based analysis
- Workforce diversity visualization
- Interactive filters and slicers for dynamic analysis

---

## 🛠 Tools & Technologies
- **Power BI** – Dashboard creation & visualization  
- **Excel / CSV** – Data source  


---

## 🗂 Dataset Description
The dataset includes the following attributes:
- Employee ID
- Age
- Gender
- Department
- Job Role
- Salary
- Experience
- Performance Rating
- Attrition (Yes/No)
- Joining Date

---

## 💡 Business Insights
- Identifies departments with high attrition
- Helps understand the relationship between salary and performance
- Highlights diversity gaps within the organization
- Assists in workforce planning and retention strategies
